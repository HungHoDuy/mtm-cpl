Application

Solova Project Management Webapp

Solova is an open-source, self-hosted project manager that combines Kanban boards with a client CRM, contracts, time tracking and double-entry accounting, aimed at freelancers and small studios.

Main features

  • Companies (CRM): Client records with billing models (retainer / per-project / per-task / hourly), contracts, and a per-company finance view: expected vs actual income and outstanding balance
  • Contacts: Many contacts per company with email, phone, mobile, WhatsApp and Telegram quick-links, added when you create the company
  • Kanban boards: Drag-and-drop lists and cards, labels, checklists (turn an item into a card), comments, attachments, photo covers, due dates, board and card templates, archive, plus Calendar, Table and Stats views
  • Projects: Notes, typed custom fields, a website with auto-fetched favicon, per-project pricing, and linked boards
  • Accounting: Append-only double-entry ledger, invoices (draft to issued to void), payments, a product/service catalog, expenses, and P&L and balance sheet reports
  • Dashboard: Contribution heatmap, open/closed and label charts, income per month, and expected-vs-actual per client
  • Time tracking: One-click start/stop timer plus manual entries that feed billing and the activity heatmap
  • Notes: A sticky-note pinboard for quick thoughts

Company Tools

Each match has its own MCP server with the company's internal systems for that match, besides the source code. The exam decides which systems are available.

Connect your agent

  • URL: https://masterthemachine.tech/api/v1/mcp/Y1KH6CB9
    • The Match ID is the 8-character ID shown on /match.
    • Each match has its own URL.
  • Transport: MCP Streamable HTTP (JSON-RPC 2.0), JSON responses.
  • Auth: Authorization: Bearer <TEAM_API_KEY>. This is the same API key you use to start work and submit.

Discover the tools

Call tools/list to see which tools the company provides in this match. MCP clients such as Codex do this automatically at startup.

  • Each tool description explains what the system holds, when engineers use it, and its parameters.
  • Information from these systems is authoritative and overrides assumptions.
  • Appropriate use of company systems is part of process quality.

Availability

  • initialize and tools/list work from preparation onwards, so you can check your connection early.
  • Tools return content only after the match has started.
  • Content about a backlog item becomes available only after that item appears on /match.

Errors

  • HTTP 401 or 403: the API key is wrong, revoked, or missing scope, or your team is not in this match.
  • HTTP 404: unknown Match ID.
  • Business errors come back inside the tool result with isError: true and JSON { "error": { "code", "message" } }.
  • Rate limit: 120 requests per minute per API key.

Every tool call is recorded with your team and match.
